# JavaScript - Práticas Iniciais

Este repositório contém exercícios desenvolvidos durante meus estudos de JavaScript, com o objetivo de praticar conceitos básicos da linguagem e manipulação do DOM.

## Projetos

- **Calcular Média:** calcula a média de três notas e verifica se o aluno foi aprovado ou reprovado.
- **Verificar Idade:** verifica se uma pessoa é maior ou menor de idade.
- **Mensagem de Boas-vindas:** recebe o nome do usuário e exibe uma mensagem personalizada.
- **Calculadora de Soma:** soma dois números informados pelo usuário.

## Tecnologias utilizadas

- HTML5
- JavaScript

## Objetivo

Praticar os fundamentos de JavaScript e desenvolver projetos simples para meu aprendizado e portfólio.
